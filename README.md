# BodyWords 身語集

分析文本中**情感與器官的對應**，並以科學解剖風格的**人形圖**視覺化呈現不同器官的情緒狀態。

## 功能

- 📄 上傳 txt 文本（自動識別「第X回/章」章節）
- 🧠 自動識別人物名稱
- 🫀 按字面描寫統計器官-情緒對應（如「羞紅了臉」計入【臉】）
- 🎨 人形解剖圖：以顏色色系（情緒種類）、深淺（強度）表現各器官情緒狀態
- 🖱️ 點擊器官查看對應原文片段
- 📚 目錄：書 / 章 / 人物 各自的人圖
- 🩻 縱向動態對比（醫學切片式）：章節間、人物間的人圖並排對比
- 🌐 繁體中文 / English 切換
- 🔐 鏈接密鑰訪問控制（只有拿到含密鑰鏈接的人可訪問）

## 運行

```bash
cd bodywords
pip install -r requirements.txt
python app.py
```

打開 http://127.0.0.1:5000 ，首次訪問會要求輸入管理密碼（默認 `bodywords`，可在 `config.json` 修改），登入後可生成/管理分享鏈接。

## 技術

- 後端：Python + Flask（數據不暴露，保密性較好）
- 前端：HTML/CSS/JS + SVG 人形解剖圖
